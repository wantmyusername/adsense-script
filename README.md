# AdSense Script
### Script de Bloqueo de Pantalla y Maximización de Anuncios para AdSense
Este archivo implementa una función para bloquear la pantalla y desplegar un botón emergente al realizar scroll down . Al hacer clic en el botón, se activa el anuncio Full Screen Modal de AdSense. Aunque esta técnica no infringe las políticas de AdSense, es importante destacar que puede afectar negativamente la usabilidad y la experiencia del usuario al dificultar la navegación fluida y la interacción con el contenido.

Este script es una especie de mirror de la caracteristica de Ezoic: Expanded Article.
https://support.ezoic.com/kb/article/what-is-the-expanded-article-feature

Es necesario tener anuncios automáticos para que funcione.
